# Revenue Cloud Field Notes

A single-file study app for the Salesforce Certified Agentforce Revenue Management Consultant exam.

**Live version:** enable GitHub Pages on this repo (Settings → Pages → Deploy from branch → `main` → `/root`), then visit `https://<your-username>.github.io/<repo-name>/`

## What's inside

Three tabs, all sharing the same 18 topic chips (Context Service, Pricing/BRE, Advanced Configurator, Qualification, Contracts, Assets, Billing, DRO, Permissions, Approvals, APIs, Order Mgmt, Project Delivery, OmniStudio, Agentforce, Reporting, Catalog Mgmt):

- **Cards** — 150+ flashcards, tap to flip, star to drill again
- **Concepts** — read-through explainer cards on how the pieces fit together (object relationships, decision frameworks, setup sequences)
- **Checklist** — hands-on sandbox tasks per topic, with progress saved in your browser

Pick a chip, then use Prev/Next to page through everything in that topic — same interaction pattern across all three tabs.

## Sourcing

Built from the official Salesforce exam guide, official Salesforce Help/Developer documentation, and The Cloud Update's tutorials — cross-checked against exam-dump sites only to identify *topic shapes*, never to source answers.

## Usage

Just open `index.html` in any browser — no build step, no dependencies. Works offline once downloaded. Progress (starred cards, checklist completion) is saved locally in your browser via `localStorage`, so it won't sync across devices or browsers.
